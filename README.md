# CamWard — versions publiées

Ce dépôt ne contient que les versions publiées de **CamWard**, l'outil de Sarto Groupe pour préparer et réceptionner les caméras d'un chantier. Le code source n'y est pas.

Chaque version est accompagnée d'un fichier `version.json` signé par Sarto Groupe. Avant de proposer une mise à jour, CamWard vérifie cette signature, l'empreinte du fichier et le numéro de version, et refuse tout le reste — même venu de ce dépôt. Rien ne s'installe sans l'accord de la personne devant le PC.

Installer à la main : télécharger `CamWard.exe` depuis la [dernière version](https://github.com/sarto-groupe/camward-releases/releases/latest) et le ranger où l'on veut (bureau, Documents) — pas dans Program Files, pour qu'il puisse se mettre à jour lui-même.
